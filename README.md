# Atomic Timer

A speedcubing timer for the web — desktop-first, great on phones, installable as a PWA — with Android and iOS apps built from the same codebase via Capacitor. WCA scrambles for every official puzzle (via [cubing.js](https://js.cubing.net/cubing/)), sessions, rolling averages, graphs, and import from Cubic Timer, Twisty Timer and csTimer.

Inspired by [Cubic Timer](https://github.com/hato-ya/CubicTimer) by hatoya and [Twisty Timer](https://github.com/aricneto/TwistyTimer) by Ariovaldo Neto. Atomic Timer is an independent, clean-room implementation and contains no code or assets from either project.

## Development

```bash
npm install
npm run dev        # dev server
npm test           # unit tests
npm run test:e2e   # Playwright end-to-end tests
```
